# Matchprint design rationale

Warm paper, deep turf green, muted highlighter, condensed editorial headings, monospace match metadata, a restrained stadium cover, ticket receipts, a fine fixture spine, and split numerical score compartments implement the supplied visual direction. The navigation is a clubhouse, with the matchday task occupying the largest area. Team names use original letter shields rather than unlicensed official crests.

Fixture cards retain the same scoring semantics on desktop and phone. At narrow widths, cards become a single column, the side navigation collapses, and the submission dock remains reachable. The hero was corrected after a 320px clipping issue was observed. Hidden mobile navigation is removed from the accessibility tree using visibility.

This is an original composition from the brief. No claim of worldwide uniqueness or a completed five-competitor visual audit is made. The competitor comparison, complete contrast audit, 200% zoom evaluation, screen-reader audit and touch-target review remain release work. Current font family choices are Barlow Condensed, DM Sans and IBM Plex Mono.
